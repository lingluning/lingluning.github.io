开发日志 | openEarth2D —— 地形模型生成工具

Posted on 2026-05-15 | In Dev

项目背景

在土木和建筑工程中，常常需要将真实地形导入 3D 软件进行方案设计与分析。 传统做法是购买商业 GIS 数据，或手动从地图软件导出，流程繁琐且成本高。

日本国土地理院（GSI）提供了免费的高精度数值标高模型（DEM）API 和无缝航拍影像服务。 于是我开发了 openEarth2D——一个纯前端的地形模型生成工具， 只需在地图上点选位置，即可自动获取真实地形数据并生成带航拍贴图的 3D 文件，直接导入 SketchUp Go 使用。

功能介绍

🗺️ 交互式地图选点

基于 Leaflet.js 集成国土地理院地图（标准地图 + 航拍影像双图层切换）， 支持三种选点方式：

  • 直接点击地图
  • 拖动红色标记点
  • 手动输入经纬度坐标

选点后自动显示红色虚线框标注生成范围，并实时更新实际尺寸和高程采样点数。

⛰️ 高程数据自动获取

通过国土地理院的 getelevation.php API， 对网格内每个采样点逐一请求真实高程值（单位：米），每批 5 个并行请求， 最多支持 51×51 = 2601 个采样点，网格间距最小约 20m（1km 范围下）。

📸 航拍影像自动拼接

从国土地理院的 Seamless Photo 服务拉取 Zoom 16 级的 256×256 瓦片图， 利用 Canvas API 拼接为完整影像后裁剪至精确的 BBox 范围， 输出最大 2048×2048px 的 JPEG 贴图。

📦 多格式 3D 文件导出

支持三种导出模式：

  • DAE（Collada）推荐： 生成完整 Collada 1.4.1 格式，UV 坐标与航拍影像精确对应， 导入 SketchUp Go 后航拍照片自动贴合地形，无需手动操作
  • STL： 生成二进制 STL 格式，包含法向量计算，适合 3D 打印或其他软件使用
  • 两者同时导出：DAE + STL 打包在同一 ZIP 中

最终输出为 terrain.zip，包含 3D 文件、航拍贴图（terrain_aerial.jpg） 和详细的 README.txt（含中心坐标、实际尺寸、网格参数、导入步骤）。

技术栈

  • Leaflet.js（v1.9.4）：交互式地图，支持地图点击与标记拖拽
  • JSZip（v3.10.1）：浏览器端打包 ZIP 文件
  • Canvas API：瓦片图拼接与裁剪
  • Fetch API：并行请求高程数据（每批 5 个）
  • Vanilla JavaScript：纯原生 JS，无框架依赖
  • 国土地理院 API：getelevation.php（高程）+ seamlessphoto（航拍瓦片）

实现亮点

DAE 格式的 UV 贴图对齐

DAE（Collada）格式中，UV 坐标的 V 轴方向（下→上）与图像坐标系（上→下）相反。 工具中通过 v = (N-1-r)/(N-1) 正确翻转 V 轴， 确保航拍影像与地形网格精确对齐，不产生上下颠倒的问题。

无服务器纯前端架构

整个工具只有一个 HTML 文件，所有依赖通过 CDN 加载， 高程数据与航拍图像直接从国土地理院服务器获取， 不需要任何后端服务器，可以直接在本地打开或部署到 GitHub Pages。

坐标系转换

经纬度到实际米数的转换需要考虑纬度修正：

  • 纬度方向：1° ≈ 110,540m（固定）
  • 经度方向：1° ≈ 111,320 × cos(纬度)（随纬度变化）

最终 3D 模型的 X/Y 坐标单位为米，Z 为高程（米），与 SketchUp 的坐标系（Z_UP）一致。

实时进度反馈

高程请求（55%进度）→ 航拍获取（25%）→ 文件生成（17%）三阶段进度条， 配合终端风格的日志输出，完整记录每一步的执行结果（绿色 OK / 红色 Error / 蓝色 Info）。

使用方式

  1. 在地图上点选目标位置（或输入经纬度）
  2. 设置范围（推荐 0.5～2km）和网格密度（推荐 21～31）
  3. 选择输出格式（推荐 DAE）
  4. 点击「生成开始」，等待数据获取完成
  5. 下载 terrain.zip，解压后将 terrain.dae 和 terrain_aerial.jpg 放在同一文件夹
  6. SketchUp Go → File → Import → 选择 COLLADA (*.dae) → 导入 terrain.dae

总结

openEarth2D 是一个将 GIS 公开数据与 3D 工程软件打通的实用小工具。 整个项目只有一个 HTML 文件，却实现了地图交互、批量 API 请求、Canvas 图像处理、 3D 几何体生成、多格式文件打包等功能，充分体验到了浏览器原生能力的强大。

后续计划支持更多地区的高程数据源（如 SRTM、Mapbox Terrain）， 以及更精细的网格插值算法（双三次插值）来提升模型质量。
