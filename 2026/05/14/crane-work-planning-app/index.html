开发日志 | 移动式起重机作业计划 Web App

Posted on 2026-05-14 | In Dev

项目背景

在日本建筑工地，移动式起重机（移動式クレーン）作业前必须制作详细的作业计划书，标明起重机的配置位置、吊荷位置、禁止区域和通行路线，并由管理人员签认。 传统做法是手绘或用 AutoCAD 制图，流程繁琐、效率低。

为解决这个问题，我开发了这款纯前端的 移动式起重机作业计划 Web App， 让工地管理人员可以在浏览器中快速完成 3D 可视化布置和计划书生成，无需安装任何软件。

👉 GitHub 仓库：lingluning/crane-app

功能介绍

🏗️ 3D 可视化布置

基于 Three.js 构建 3D 场景，用户可以在俯视地面上通过工具面板自由放置各类元素：

  • 🏗️ 起重机（クレーン）：使用 TADANO GR-250N 25t 起重机模型，可调整作业半径（5～15m）和旋转角度（0～360°）
  • 📦 吊荷（吊荷）：标记需要吊装的货物位置
  • 🟨 铺铁板（敷鉄板）：为起重机提供稳定支撑面，支持 1.5×3、2×4、1×2 三种规格，自动网格对齐
  • 🚫 禁止区域（立入禁止区）：多边形绘制，标记人员不得进入的危险区域
  • 🟢 通行路线（通路）：多段线绘制，标记人员和车辆通行路径
  • 📏 距离测量（測定）：点击两点即可测量实际距离

🛡️ 安全检查

右侧安全面板实时显示三项安全状态：

  • 作业半径：起重机作业范围是否合规
  • 吊荷位置：吊荷是否在起重机作业半径内
  • 通路重叠：通行路线是否与禁止区域发生冲突

📋 作业计划书自动生成

点击「計画書作成」按钮，弹出表单，填写现场信息、起重机型号、人员分工、作业内容和安全条件后， 一键生成 PDF 格式的移动式起重机作业计划书，满足日本建筑工地的合规要求。

💾 数据保存与导入导出

  • 自动保存（Auto Save）到浏览器本地存储
  • 手动保存 / 读取项目状态
  • JSON 格式导出与导入，方便团队共享
  • 「3視図出力」：一键截取俯视图、正视图、侧视图三视图

技术栈

  • Three.js（v0.160）：3D 场景渲染、几何体创建、射线检测（Raycaster）、CSS2D 标签
  • Tailwind CSS：UI 样式，纯 CDN 加载，无需构建工具
  • Vanilla JavaScript (ES Modules)：模块化架构，分为 scene、state、tools、safety-tools、persistence、export 等模块
  • 浏览器原生 API：LocalStorage 持久化、File API 文件导入、Canvas 截图
  • Import Maps：在浏览器中直接使用 ES Module 版本的 Three.js，无需打包器

实现亮点

模块化架构

项目将功能拆分为独立模块（scene.js、state.js、tools.js、 safety-tools.js、persistence.js、export.js）， 通过 ES Module 互相引用，代码结构清晰，便于维护。

多边形禁止区域绘制

使用 Three.js 的 THREE.Shape 实现任意多边形禁止区域绘制， 绘制过程中以虚线实时预览，Enter 确认、ESC 取消，体验流畅。

网格吸附（Grid Snap）

铺铁板放置时自动吸附到网格，确保铁板整齐排列，更贴近实际工地施工规范。

无构建工具部署

整个应用仅是一个 index.html + 若干 .js 文件， 利用浏览器原生 Import Maps 加载 Three.js CDN，无需 Webpack / Vite， 直接 GitHub Pages 托管即可使用。

总结

这个项目把土木工程的实际需求与前端 3D 技术结合起来，是我第一次用 Three.js 做完整的工程应用。 整个开发过程让我对 3D 坐标系、射线检测、几何体构建有了更深的理解， 也体会到「无构建工具的纯前端架构」的简洁之美。

后续计划增加：多种起重机型号支持、地面承载力计算、云端协作保存等功能。
